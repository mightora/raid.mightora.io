Privacy by design

No upload. No account. No black box.

All workbook reading, changes, rule-based assessments and document generation happen inside your browser. The application logic does not upload imported register data. The online edition loads remotely maintained shared UI resources, so the downloadable offline edition is preferable for highly confidential material and makes no network requests.

Verify network requests yourself

Press F12, open Developer Tools → Network, select Preserve log, reload and inspect requests. The online edition may request static JavaScript, stylesheet and image resources. The resource request summary below is only indicative and does not replace Developer Tools or an independent audit.
